

О программе «Поддавки»

Программное приложение «Поддавки» предназначено для проведения настольной игры в поддавки с возможностью участия человека против компьютерного соперника или двух игроков на одном персональном компьютере.
Программа предоставляет пользователю средства регистрации и авторизации, настройки сложности компьютерного соперника, ведения статистики, просмотра истории партий, сохранения и загрузки игрового процесса.
Приложение разработано на языке программирования C# с использованием Windows Forms. Для хранения пользовательских данных применяется локальная база данных SQLite.

Запуск программы

Для запуска приложения необходимо выполнить файл Poddavki.exe или воспользоваться установочным файлом setup, предварительно выполнив установку программы.
После запуска отображается окно авторизации. Пользователь может войти в существующую учётную запись либо перейти к созданию нового профиля.

 Регистрация и авторизация

Для создания новой учётной записи необходимо выбрать соответствующий пункт на форме авторизации. В открывшемся окне регистрации требуется указать логин, пароль и подтверждение пароля.
Логин и пароль должны содержать от 3 до 20 символов. После заполнения полей необходимо нажать кнопку создания учётной записи.
Если данные введены корректно и указанный логин ещё не используется, создаётся новый пользовательский профиль.
Для входа в приложение необходимо указать ранее зарегистрированные логин и пароль и нажать кнопку авторизации. При успешной проверке данных открывается главное меню программы.
Если введены неправильные данные или обязательные поля остались незаполненными, приложение выводит соответствующее информационное сообщение.

Главное меню программы

После успешной авторизации пользователь попадает в главное меню. Оно предоставляет доступ к основным возможностям приложения:
•	запуск игры против компьютерного соперника;
•	запуск игры для двух игроков;
•	просмотр профилей и статистики;
•	просмотр истории игровых партий;
•	изменение настроек приложения.
Выбор необходимого режима осуществляется нажатием соответствующей кнопки интерфейса.

 Настройка сложности

Перед началом игры против компьютера пользователь может выбрать уровень сложности компьютерного соперника в разделе настроек.
В приложении предусмотрено три уровня сложности. Изменение уровня сложности влияет на глубину поиска алгоритма искусственного интеллекта и, соответственно, на количество игровых вариантов, анализируемых компьютером при выборе хода.
После выбора необходимого уровня настройка сохраняется и применяется при последующих запусках игры.

Игровой процесс

В приложении предусмотрено два режима игры:
1.Игра против компьютера. Пользователь управляет шашками одной стороны, а противоположной стороной управляет искусственный интеллект.
2.Игра для двух игроков. Два человека поочерёдно выполняют ходы на одном компьютере.
Игровое поле представляет собой доску размером 8×8 клеток. Для выполнения хода необходимо выбрать собственную шашку, а затем указать допустимую клетку назначения.
При наличии возможности взятия действует правило обязательного взятия. Если после выполнения взятия возможно продолжение комбинации, игрок должен продолжить ход той же шашкой.
При достижении противоположной стороны доски обычная шашка превращается в дамку. Дамка обладает расширенными возможностями перемещения и взятия.
Победителем становится участник, который первым достигает условия победы в соответствии с правилами поддавков: избавляется от всех своих шашек либо оказывается без возможных ходов.
Во время партии пользователь может отслеживать текущее состояние игрового поля, очки участников, продолжительность игры и журнал выполненных ходов.

Сохранение и загрузка партий

Приложение предусматривает возможность сохранения текущей партии и последующего восстановления игрового процесса.
Для сохранения необходимо воспользоваться соответствующей кнопкой в игровом интерфейсе и указать имя сохранения.
Для продолжения ранее сохранённой партии необходимо открыть список сохранений, выбрать нужную запись и выполнить загрузку.
Также предусмотрено автоматическое сохранение текущей партии при определённых действиях пользователя, например при выходе из игры или возврате в главное меню. При повторном запуске приложение может предложить продолжить ранее начатую партию.

Просмотр профилей и статистики

В разделе профилей пользователь может просматривать сведения об учётных записях и результаты проведённых партий.
Статистика содержит сведения о результатах игр, включая количество побед и поражений. Данные используются для отображения игровой активности пользователя.
Дополнительно предусмотрен просмотр истории партий, позволяющий ознакомиться с ранее проведёнными игровыми сессиями.

Завершение работы

Для завершения текущей партии и возврата в главное меню необходимо воспользоваться соответствующей кнопкой игрового интерфейса.
Если партия ещё не завершена, приложение может предложить сохранить её состояние перед выходом.
Для полного завершения работы следует закрыть главное окно приложения.

Особенности хранения данных

Пользовательские профили, статистика и игровые данные сохраняются в локальном хранилище приложения. База данных создаётся в каталоге пользовательских данных Windows.
При переносе исполняемого файла на другой компьютер локальная база данных автоматически не переносится. Поэтому ранее созданные учётные записи и сохранённые партии не становятся доступными на другом компьютере без отдельного переноса соответствующих данных.
Таким образом, приложение «Поддавки» предоставляет пользователю основные средства для организации игрового процесса, управления профилем, настройки компьютерного соперника и сохранения результатов партий.
