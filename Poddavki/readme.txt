# Поддавки

## 1. Описание проекта

«Поддавки» — настольная игра в шашки с обратной целью (игра в поддавки), разработанная на языке C# с использованием Windows Forms.

Приложение позволяет играть против искусственного интеллекта или вдвоём на одном компьютере. Программа поддерживает регистрацию пользователей, сохранение партий, просмотр истории игр и ведение статистики.

## 2. Основные возможности

- Регистрация и авторизация пользователей.
- Игра против искусственного интеллекта.
- Игра вдвоём на одном компьютере.
- Три уровня сложности ИИ.
- Соблюдение правил игры, включая обязательное взятие и множественные взятия.
- Превращение шашек в дамки.
- Сохранение и загрузка игровых партий.
- Автоматическое сохранение незавершённых партий.
- Продолжение последней незавершённой игры.
- Просмотр профилей и игровой статистики.
- Просмотр истории завершённых партий и последовательности ходов.
- Экспорт истории партии в текстовый файл TXT.

## 4. Структура проекта

Решение состоит из пяти проектов.

### Poddavki

Основное приложение Windows Forms.

Содержит:
- GameForm — игровое окно;
- LoginForm — авторизация;
- RegisterForm — регистрация;
- MainMenuForm — главное меню;
- ProfilesForm — профили и статистика;
- SettingsForm — настройки сложности;
- HistoryForm — история партий;
- Program — точка входа приложения.

### Poddavki.Core

Содержит основные игровые структуры и логику игрового поля.

Основной класс:
- GameBoard — игровое поле и начальная расстановка шашек.

### Poddavki.AI

Отвечает за работу искусственного интеллекта.

Основные классы:
- AIPlayer — алгоритм выбора хода;
- AIMove — описание выбранного хода и последовательности взятий.

### Poddavki.Data

Отвечает за хранение и обработку данных.

Основные классы:
- DatabaseInitializer — создание и инициализация базы данных;
- UserRepository — регистрация, авторизация и управление профилями;
- GameRepository — сохранение партий, история и работа с ходами;
- PasswordHasher — хеширование и проверка паролей;
- UserProfile — модель пользователя;
- SaveState — модель сохранённой партии;
- CompletedGame — модель завершённой партии.

### Poddavki.Tests

Содержит автоматические тесты игровых механизмов, искусственного интеллекта, хранения данных, истории партий и проверки паролей.

## 5. Хранение данных

Для хранения информации используется SQLite.

Основной файл базы данных — `poddavki.db`. Он располагается в каталоге приложения.

В базе данных используются следующие таблицы:

|     Таблица 	 | 		   Назначение                  |
|================|=============================================|
|      Users 	 |           Пользователи и статистика         |
|      Games 	 |      Сохранённые и незавершённые партии     |
|      Moves 	 |    Ходы, связанные с сохранёнными партиями  |
| CompletedGames |          История завершённых партий         |
| CompletedMoves | Последовательности ходов завершённых партий |

Пароли пользователей не хранятся в открытом виде. Для их защиты используется хеширование PBKDF2 с индивидуальной солью.

Настройки сложности искусственного интеллекта сохраняются отдельно в файле `difficulty.txt`.

## 6. Запуск приложения

Для запуска из среды разработки необходимо:

1. Установить Visual Studio с поддержкой разработки приложений Windows Forms на C#.
2. Установить .NET Framework 4.7.2 Developer Pack.
3. Открыть файл решения `Poddavki.slnx`.
4. Выполнить восстановление NuGet-пакетов.
5. Убедиться, что проект `Poddavki` назначен запускаемым.
6. Выполнить сборку решения.
7. Запустить приложение клавишей F5.

После запуска открывается окно авторизации. Новый пользователь может создать учётную запись через форму регистрации.

## 7. Запуск автоматических тестов

В проекте `Poddavki.Tests` используется MSTest.

Для запуска тестов необходимо:

1. Открыть решение в Visual Studio.
2. Перейти в меню «Тест».
3. Открыть «Обозреватель тестов».
4. Нажать «Запустить все тесты».

В проекте реализован 21 автоматический тест.

Проверяются:
- начальная расстановка шашек;
- восстановление игрового поля;
- выбор ходов искусственным интеллектом;
- обязательное и множественное взятие;
- сохранение и удаление игровых данных;
- запись истории партий;
- получение последовательности ходов;
- проверка хеширования паролей.

По результатам последнего запуска все 21 теста пройдены успешно.

## 8. Экспорт партий

В приложении предусмотрен экспорт завершённых партий.

Для экспорта необходимо:

1. Открыть раздел истории партий.
2. Выбрать интересующую партию.
3. Нажать кнопку «Экспорт».
4. Выбрать место сохранения файла.

История сохраняется в формате TXT и содержит дату, режим игры, результат, продолжительность, количество ходов и последовательность ходов.

## 9. Требования к системе

- Операционная система Windows.
- Установленная среда .NET Framework 4.7.2 или совместимая более новая версия.
- Достаточное свободное место для приложения и базы данных.
- Наличие необходимых библиотек SQLite в каталоге приложения.

## 10. Заключение

Приложение «Поддавки» реализует игровой процесс, управление пользователями, хранение игровых данных, просмотр истории партий и экспорт результатов.

Проект разделён на отдельные модули, что упрощает сопровождение и дальнейшее развитие программы. Работоспособность основных компонентов проверена вручную и с помощью автоматических тестов.
